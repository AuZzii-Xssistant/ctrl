Powered by WinScript

Builder is an imported sub-module of WinScript, built into >_ CTRL.

The category toggles, presets, and script generation you see here all trace back to WinScript — a standalone Windows debloat/privacy/tweak tool. Builder ports that engine into >_ CTRL rather than reinventing it.

Because it's an import, behaviour can drift from the original over time: >_ CTRL may add, change, or fix things WinScript doesn't have (or vice versa) as each project keeps evolving on its own.

WinScript on GitHub Support on Ko-fi

You don't need the standalone WinScript app to use Builder — everything here runs in >_ CTRL, just head to Run Script below to build and run a script. But if Builder's been useful to you, consider stopping by WinScript's page to support the developer who originally built it.
